# Primary references

- **A Student's Guide to Bayesian Statistics** (owned_unindexed, core)
  Source: `fixtures/textbooks/lambert_students_guide_bayesian_statistics.pdf`
  Notes: Best beginner-to-computation bridge in the local library.

- **Lambert problem set solutions (Hotti)** (owned_unindexed, core)
  Source: `fixtures/library_books/companion_repos/lambert_solutions_hotti`
  Notes: Python-heavy worked solutions, including MCMC, Gibbs, HMC, Stan, and hierarchical examples.

- **BDA Python demos** (owned_unindexed, core)
  Source: `fixtures/library_books/companion_repos/BDA_py_demos`
  Notes: Jupyter demos for BDA chapters 2, 3, 4, 5, 6, 10, and 11 plus CmdStanPy examples.

- **BDA R demos** (owned_unindexed, core)
  Source: `fixtures/library_books/companion_repos/BDA_R_demos`
  Notes: Posterior predictive, model checking, and Stan/R ecosystem demos.

- **Aalto Bayesian Data Analysis course materials** (owned_unindexed, core)
  Source: `fixtures/library_books/companion_repos/BDA_course_Aalto`
  Notes: Complete course spine with schedule, assignments, demos, notes, and slides.

- **Bayesian Workflow** (external_target, core)
  Source: https://arxiv.org/abs/2011.01808
  Notes: The main philosophical and practical workflow paper for the track.

- **Practical Bayesian model evaluation using leave-one-out cross-validation and WAIC** (external_target, core)
  Source: https://arxiv.org/abs/1507.04544
  Notes: Model comparison backbone.

- **Rank-normalization, folding, and localization: An improved R-hat** (external_target, core)
  Source: https://arxiv.org/abs/1903.08008
  Notes: Modern convergence diagnostics.

- **Validating Bayesian Inference Algorithms with Simulation-Based Calibration** (external_target, core)
  Source: https://arxiv.org/abs/1804.06788
  Notes: Computational validation that most pedagogical repos skip.

- **The No-U-Turn Sampler** (external_target, core)
  Source: https://jmlr.org/papers/v15/hoffman14a.html
  Notes: Primary HMC/NUTS reference.
