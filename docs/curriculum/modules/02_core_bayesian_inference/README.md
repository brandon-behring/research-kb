# Core Bayesian Inference

**Module ID**: `02_core_bayesian_inference`
**Prerequisites**: `01_probability_and_stat_baseline`
**Goal**: Introduce priors, posteriors, conjugacy, posterior predictive thinking, and decision framing with simple models.

## Primary materials

- **A Student's Guide to Bayesian Statistics**: Best beginner-to-computation bridge in the local library. (`fixtures/textbooks/lambert_students_guide_bayesian_statistics.pdf`)
- **Bayesian Statistics for Beginners**: Gentle posterior-thinking introduction. (`fixtures/textbooks/migrated/therese_m_donovan__ruth_m_mickey_-_bayesian_statis_nd.pdf`)
- **Bayesian Statistics: An Introduction**: Conceptual Bayes treatment after the beginner text. (`fixtures/textbooks/migrated/lee_peter_-_bayesian_statistics__an_introduction-j_nd.pdf`)
- **Think Bayes 2**: Computational Bayes text with open notebooks. (https://allendowney.github.io/ThinkBayes2/)

## Support materials

- **Lambert problem set solutions (Castillo)**: Worked exercises and data for Lambert chapters. (`fixtures/library_books/companion_repos/lambert_solutions_castillo`)
- **Lambert problem set solutions (Hotti)**: Python-heavy worked solutions, including MCMC, Gibbs, HMC, Stan, and hierarchical examples. (`fixtures/library_books/companion_repos/lambert_solutions_hotti`)
- **Introduction to Bayesian Statistics (Bolstad)**: Backup introductory text if you want another worked style. (`fixtures/library_books/[William_M._Bolstad]_Introduction_to_Bayesian_Stat(Bookos.org).pdf`)
