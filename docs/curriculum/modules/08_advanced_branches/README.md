# Advanced Branches

**Module ID**: `08_advanced_branches`
**Prerequisites**: `07_time_series_and_forecasting`
**Goal**: Split into advanced optional branches once the trunk is stable: probabilistic ML and causal/Bayesian decision work.

## Primary materials

- **Probabilistic Graphical Models**: Advanced branch entry for structured probabilistic modeling. (`fixtures/textbooks/koller_friedman_pgm_2009.pdf`)
- **Probabilistic Machine Learning: An Introduction**: Modern probability-first ML framing. (`fixtures/library_books/Kevin P. Murphy - Probabilistic Machine Learning_ An Introduction-The MIT Press (2021).pdf`)

## Support materials

- **Machine Learning: A Probabilistic Perspective**: Broad probabilistic modeling reference. (`fixtures/library_books/(Adaptive Computation and Machine Learning series) Kevin P. Murphy - Machine Learning_ A Probabilistic Perspective-The MIT Press (2012).pdf`)
- **Probabilistic Machine Learning: Advanced Topics**: Advanced optional continuation for VI, deep generative models, and beyond. (https://probml.github.io/pml-book/book2.html)
- **Applied Bayesian Modeling and Causal Inference from Incomplete-Data Perspectives**: Optional causal-Bayes branch only after the trunk is complete. (`fixtures/textbooks/Applied Bayesian modeling and causal inference from -- Donald B Rubin; Andrew Gelman; Xiao-Li Meng -- Wiley Series in Probability and Statistics, -- 9780470090435 -- 6b4631b748ce7a0ce1b9e18edbfee08c -- Anna’s Archive (1).pdf`)
- **Existing causal inference library**: Use only after regression, hierarchy, and model checking are solid. (`docs/owned_inventory.json`)
- **Bayesian MMM paper set**: Optional marketing and decision branch. (`fixtures/papers/mmm_google`)

## Optional materials

- **Bayesian Optimization in Action**: Useful, but not part of the trunk path. (`Documents/Manning_Books_research_kb/Bayesian Optimization in Action/Bayesian_Optimization_in_Action.pdf`)
- **Auto-Encoding Variational Bayes**: Variational inference anchor for the advanced branch. (https://arxiv.org/abs/1312.6114)
