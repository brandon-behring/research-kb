# AR(1) to local-level forecasting ladder

Start with AR(1) simulation, then move to a local-level state-space model and evaluate one-step-ahead forecasts.

## Deliverable

- A short note or notebook that states the modeling goal, the data source, the candidate models, and the evaluation rule.

## Completion criteria

- Satisfies the module checkpoint: You can fit one ARIMA/state-space/Bayesian forecast model and evaluate calibration or forecast error on held-out data.
- Cites at least one primary source and one exercise/data source from this module.
