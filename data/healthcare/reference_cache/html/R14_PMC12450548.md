# The Use of Real-World Evidence Among Healthcare Payers: A Scoping Review

**Journal:** Int J Technol Assess Health Care, 2025;41(1):e67
**DOI:** 10.1017/S0266462325100445
**Authors:** Masucci, Lewis, Zhao, Carter, Chan, Wong (U of Toronto / U of Waterloo / Sunnybrook)

## Key Findings

### Study Characteristics
- 19 articles analyzed (2014-2025)
- 52% from US/Canada; oncology dominated (32%)

### Why Payers Use RWE
- Addresses RCT limitations (strict criteria, lack external validity)
- Broad patient representation and greater external validity
- Captures long-term outcomes beyond short study timeframes
- Evidence for rare diseases

### Major Barriers
**Quality concerns** (7 studies): Bias, confounding, lack of standardization
**Data access** (7 studies): Legal/privacy constraints; prospective data takes 3-7 years; high costs
**Data integrity**: Incomplete datasets, inconsistent outcome definitions
**Transparency**: Absence of reporting standards

### Funding Arrangements Using RWE
- **Risk-sharing/OBAs**: Conditional access while collecting performance data
- **Coverage with evidence development**: RWE under research conditions
- **Financial-based MEAs**: More common due to easier implementation
- Only 17% reported experience using RWE in OBAs

### Data Sources
| Source | Strengths | Limitations |
|---|---|---|
| Registry | Reflects clinical practice | Costly, susceptible to bias |
| Claims | Readily available, cost-effective | Better for utilization/cost |
| EHR | Clinical variables | Variable completeness |

## Recommendations
1. Standardize RWE collection/analysis methods
2. Enable data sharing addressing legal/privacy concerns
3. Develop transparent HTA integration frameworks
4. Foster payer-manufacturer-researcher collaboration
