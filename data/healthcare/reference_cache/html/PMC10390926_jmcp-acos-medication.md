# Are ACOs Ready to be Accountable for Medication Use?

**Authors:** Dubois, Feldman, Lustig, Kotzbauer, Penso, Pope, Westrich (NPC / Premier / Dartmouth / AMGA)

## Key Findings (46 ACO respondents)
- **Strengths**: E-prescribing (70%), integrated medical-pharmacy databases (54%), generic-encouraging formularies (50%)
- **Gaps**: Only 7% could demonstrate medication value through cost offsets; 9% could notify MDs when Rx filled
- **45% of ACOs** have drug-spending contracts
- **Only 26%** include a pharmacy

## Critical Deficiencies
- Quantify medication cost offsets: 7%
- Notify physicians of filled prescriptions: 9%
- Prevent polypharmacy protocols: 17%
- Quality metrics for diverse conditions: 22%
- Clinical pharmacists in direct care: 22%
- Protocols for adverse event communication: 13%

## Conclusions
ACOs possess technological infrastructure but underutilize it. Significant improvements needed before fulfilling accountability mandate for medication use.
